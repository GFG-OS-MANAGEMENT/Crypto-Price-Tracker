# Contributing to Crypto Price Tracker

First of all, thank you for your interest in contributing to Crypto Price Tracker! Contributions, bug reports, feature suggestions, and improvements are welcome.

## 🤝 How to Contribute

1. **Fork the repository** to your GitHub account.
2. **Clone your fork:**
   ```bash
   git clone https://github.com/YOUR-USERNAME/Crypto-Price-Tracker.git
   ```
3. **Create a new branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and test them locally.
5. **Commit your changes:**
   ```bash
   git add .
   git commit -m "Add: describe your changes"
   ```
6. **Push your branch:**
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Open a Pull Request** explaining your changes.

## 🐛 Reporting Bugs

When reporting a bug, please include:
- A clear description of the issue.
- Steps to reproduce it.
- Expected and actual behavior.
- Screenshots or error messages, if applicable.

## 💡 Suggesting Features

Open an issue describing the proposed feature, why it would be useful, and how it could improve the project.

## 📋 Guidelines

- Keep your code clean, readable, and consistent with the existing project.
- Test your changes before submitting a pull request.
- Avoid committing API keys, passwords, or other sensitive information.
- Keep pull requests focused on a single feature or fix.
- Be respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for helping improve Crypto Price Tracker! 🚀
